# Contributing to ASC International Website

Thank you for contributing to the ASC International website project!

## Development Process

1. **Branch Naming Convention**
   - Feature: `feature/description`
   - Bug fix: `fix/description`
   - Hotfix: `hotfix/description`
   - Documentation: `docs/description`

2. **Commit Message Format**
   ```
   type: brief description

   Longer explanation if needed
   ```

   Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

3. **Pull Request Process**
   - Create PR from your feature branch to `main`
   - Fill out the PR template
   - Request review from team members
   - Address review comments
   - Merge after approval

## Code Standards

### TypeScript
- Use TypeScript for all new files
- Define proper types/interfaces
- Avoid `any` types when possible

### React Components
- Use functional components with hooks
- Keep components small and focused
- Use proper naming (PascalCase for components)

### Styling
- Use Tailwind CSS utility classes
- Follow responsive design principles
- Maintain consistent spacing and typography

### File Organization
- Keep related files together
- Use index files for cleaner imports
- Follow the established folder structure

## Testing

- Test your changes locally before pushing
- Ensure `npm run build` completes successfully
- Check for TypeScript errors with `npm run type-check`
- Run linting with `npm run lint`

## Questions?

Contact the development team for any questions or clarifications.
