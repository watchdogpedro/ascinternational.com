## Open — ranked by impact

### 1. CRITICAL: every page canonicals to the homepage

Every page on the site carries:

```html
<link rel="canonical" href="https://ascinternational.com">
```

A canonical tag declares the authoritative URL for a page. Every product page,
blog post, and comparison guide is therefore telling Google *"I am a duplicate of
the homepage, index that instead."*

This is the most damaging SEO defect a site can carry and it can collapse the
indexed footprint to a single page. Suspect it first if organic traffic looks
inexplicably flat.

**Cause:** `src/app/layout.tsx` sets `alternates.canonical` to `SITE_URL` for the
whole site, and no page overrides it.

**Fix:** give each page its own canonical (set `alternates.canonical` per page,
relative paths resolve against `metadataBase`). Removing it from the root layout
alone is not enough — pages need their own.

### 2. HIGH: 17 real pages missing from the sitemap

Four product pages being absent is the costly part.

### 3. HIGH: `/logo.png` returns 404

The Organization JSON-LD in `layout.tsx` declares `logo` as
`${SITE_URL}/logo.png`. That file does not exist. This is the image Google uses
for knowledge panels and rich results. Either add the file to `public/` or point
the schema at an existing asset.

### 4. HIGH: one broken internal link

`/products/3d-automated-optical-inspection` → 404. Linked from
`/compare/aoi-vendor-evaluation` and `/compare/single-platform-vs-best-of-breed`.
Correct URL is `/products/automated-optical-inspection`.

### 5. MEDIUM: 73 of 80 meta descriptions exceed 160 characters

Google truncates around 160. Longest run to 253 characters, so the closing pitch
never renders. Worst offenders: `/application-notes/solder-defect-root-cause-analysis`
(253), `/compare/single-platform-vs-best-of-breed` (238),
`/application-notes/implementing-closed-loop-spi-printer-feedback` (235).

Needs rewriting, not trimming — should go through Paul or Steve since it is sales copy.

### 6. MEDIUM: 55 of 80 titles exceed 60 characters

Also truncated in results. Worst is
`/blog/stencil-design-solder-paste-printing` at 110 characters. The August 23 fix
removed ~20 characters from each, which helped but did not solve it.

### 7. MEDIUM: `/tools/roi-calculator` has no metadata

It inherits the homepage title and description verbatim — a duplicate-content
signal on a page that deserves its own.

### 8. MEDIUM: two pages share one title

`/about/global-support` and `/services/technical-support` are both
"Technical Support Services". Worth deciding whether these should be two pages.

### 9. MEDIUM: 62 of 80 pages have no `og:image`

Only 18 set one. Links to the other 62 render without an image on LinkedIn.
`/og-image.png` exists and returns 200, so the default just is not being applied
sitewide.
