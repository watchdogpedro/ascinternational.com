## Step 4: What to Look For

### ✅ Success Indicators

**Direct Citations:**
- Your site URL appears in citations/sources
- Content quoted directly from your comparison pages
- Specs cited from your product pages
- "According to ASC International..." or similar attribution

**Indirect Signals:**
- Answer matches your content structure
- Uses same terminology/specifications you defined
- Follows your "when to choose X" decision framework
- Mentions specific accuracy numbers from your pages

**High-Quality Citations:**
- Cited for comparison questions (X vs Y)
- Cited for specification questions
- Cited for decision-making guidance
- Multiple citations across different pages

### ⚠️ Areas to Improve

**Not Being Cited:**
- Content may be too new (wait 1-2 weeks)
- Competitors have stronger authority on topic
- Content needs more technical depth
- Missing key terms AI engines expect

**Cited But Misrepresented:**
- Schema markup may need adjustment
- Content structure could be clearer
- Need more explicit statements/definitions
- Add more FAQ sections

## Step 6: Optimization Tips

### If You're Not Getting Cited

**1. Add More FAQ Sections**
- Convert comparison tables into Q&A format
- Add explicit "What is..." and "When should..." questions
- Use FAQPage schema markup (already done on top pages)

**2. Add Explicit Definitions**
- Start sections with: "X is defined as..."
- Use: "According to IPC-A-610..." for standards
- Include: "The key difference between X and Y is..."

**3. Strengthen Technical Authority**
- Add measurement method details (per NIST, ISO standards)
- Include tolerance specifications with standard references
- Link to industry standards (IPC, JEDEC, ISO)
- Add calibration and traceability information

**4. Improve Structured Data**
- Add HowTo schema for process explanations
- Add TechArticle schema for technical guides
- Ensure all specs use explicit units and tolerances

**5. Build External Authority**
- Get backlinks from industry publications
- Publish technical articles on LinkedIn
- Contribute to electronics manufacturing forums
- Partner with equipment manufacturers for co-marketing

### If You're Getting Cited But Misrepresented

**1. Clarify Content Structure**
- Use clearer headings: "Accuracy: ±2μm (microns)"
- Add summary boxes at section starts
- Include "Key Takeaway" callouts
- Use bullet points for lists of specs

**2. Add Context**
- Explain what specs mean: "±2μm accuracy means..."
- Compare to industry benchmarks: "vs industry typical 5μm"
- Add use case examples: "sufficient for 0201 components"

**3. Reduce Ambiguity**
- Avoid relative terms: "better", "faster", "more accurate"
- Use explicit comparisons: "3D SPI is 5x more accurate than 2D SPI"
- State trade-offs clearly: "higher cost but lower defect escape rate"

## Appendix: AI Engine Overview

### ChatGPT (OpenAI)
- **Search Capability**: Yes (with search mode)
- **Citation Style**: Inline links in answers
- **Update Frequency**: Real-time with search mode
- **Best For**: Conversational queries, explanations

### Perplexity
- **Search Capability**: Yes (always searches)
- **Citation Style**: Numbered superscripts [1], [2], etc.
- **Update Frequency**: Real-time search results
- **Best For**: Research queries, fact-checking

### Google AI Overview
- **Search Capability**: Built into Google Search
- **Citation Style**: "Sources" section with links
- **Update Frequency**: Based on Google index
- **Best For**: Quick answers in search results

### Bing Copilot
- **Search Capability**: Yes (always searches)
- **Citation Style**: Numbered superscripts in text
- **Update Frequency**: Based on Bing index
- **Best For**: Research and shopping queries

### Claude (Anthropic)
- **Search Capability**: Limited (via citations plugin)
- **Citation Style**: Varies by implementation
- **Update Frequency**: Knowledge cutoff (January 2025)
- **Best For**: Technical explanations, analysis
